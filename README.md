# Tally

A menu bar time tracker for Mac. Clock in and out with Touch ID, track any projects you like, see totals and averages.

## Install

1. Open Terminal (press Cmd + Space, type Terminal, press Enter).
2. Paste this line and press Enter:

```
curl -fsSL https://raw.githubusercontent.com/whatsonadam/tally/main/install.sh | bash -s whatsonadam/tally
```

3. If a window asks to install the Command Line Tools, click Install, wait, then paste the line again.

Tally appears in your menu bar and a short guide starts. It opens at every login. Your data stays on your Mac.

## What you can do

- Add projects with a name, colour and optional logo or photo.
- Control + a project's key clocks in or out from anywhere. Control + W lets you choose.
- Log tab: edit or add time by hand. Stats tab: totals and averages.
- Your Mac going to sleep stops the clock for you.
- Settings: Touch ID on or off, language (English, Portugues, Espanol).
